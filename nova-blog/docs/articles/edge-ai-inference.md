# 邊緣 AI 推理優化：從理論到實踐

在硬體資源有限的情境下執行 AI 模型，往往需要在延遲、功耗與準確度之間反覆權衡。以下整理幾個最有效的優化方向。

## 常見的優化技術

### 模型量化（Quantization）

將浮點權重轉換為低精度整數，是目前最廣泛採用的加速手法：

- **INT8 量化**：權重從 32-bit float 降至 8-bit integer，通常能獲得 2–4× 加速
- **量化感知訓練（QAT）**：在訓練階段就將量化誤差納入考量，減少部署後的精度損失
- **訓練後量化（PTQ）**：訓練完成後直接套用量化，无需重新訓練流程

```python
import torch

# 範例：動態量化
model_int8 = torch.quantization.quantize_dynamic(
    model, {torch.nn.Linear}, dtype=torch.qint8
)
```

### 模型剪枝（Pruning）

移除不重要的權重或神經元，降低計算量：

- **結構化剪枝**：移除整個 channel 或 filter，硬體友好
- **非結構化剪枝**：逐權重移除，精度更高但稀疏格式需特殊硬體支援

### 知識蒸餾（Knowledge Distillation）

用大模型教導小模型，讓小模型在有限參數量下仍能保留核心預測能力。

## 實務建議

1. **先 profiling 再優化** — 用工具（如 `torch.profiler`、NVIDIA Nsight）確認瓶頸所在，避免優化錯誤目標
2. **量化優先** — INT8 量化通常能在少量精度損失下獲得 2–4× 加速，是性價比最高的起始步驟
3. **注意硬體支援** — 有些邊緣晶片對 INT8/FP16 有特殊加速單元，先確認目標硬體的能力上限

## 總結

邊緣 AI 優化不是一蹴可幾，需要反覆測試與調整。從量化入手是最快能看到效果的途徑；再依序搭配剪枝與蒸餾，逐步逼近硬體的性能邊界。
